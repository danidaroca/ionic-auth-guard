1. Fundamentos Técnicos: Del Enfoque Clásico a Functional Guards Arquitectura Angular v16+
Evolución y Ventajas de CanActivateFn:

A partir de Angular 16+, el framework abandonó las clases con la interfaz CanActivate y constructores jerárquicos. El estándar actual son las Functional Guards:

  • Funciones Puras: Se ejecutan en el pipeline antes de instanciar el componente destino.
  • Inyección con inject(): Contexto de inyección directo y seguro, sin acoplar dependencias a clases ni requerir providers en módulos.
  • Redirección Atómica con UrlTree: En lugar de retornar un booleano false y llamar manualmente a router.navigate() (lo que genera condiciones de carrera y parpadeos visuales), retornar router.createUrlTree(['/login']) detiene la navegación solicitada y conmuta a la ruta de forma atómica en el mismo ciclo.
Ciclo de Vida y Persistencia de Sesión:

Cuando el usuario refresca el navegador (F5) o escribe directamente una URL, el contexto en memoria de JavaScript se destruye y reinicia por completo.

1. Usuario recarga /admin ➔ 2. Router activa guards ➔ 3. AuthService hidrata desde sessionStorage('DAM2_AUTH_SESSION') ➔ 4. Signal reactivo disponible ➔ 5. authGuard valida y permite o devuelve UrlTree('/login').

El uso de sessionStorage garantiza que los datos persistan durante la navegación activa en la pestaña, pero se limpien automáticamente al cerrarla, asegurando máxima higiene de sesión.

1. Servicio de Autenticación con Angular Signals y Persistencia (src/app/core/services/auth.service.ts) Multi-Rol & Signals
import { Injectable, signal, computed } from '@angular/core'; export interface UserSession { username: string; role: 'admin' | 'user'; isAuthenticated: boolean; } @Injectable({ providedIn: 'root' }) export class AuthService { private readonly STORAGE_KEY = 'DAM2_AUTH_SESSION'; // Estado reactivo reactivado síncronamente desde sessionStorage al arrancar private _currentUser = signal<UserSession | null>(this.readSessionFromStorage()); // Selectores computados expuestos a la aplicación public currentUser = this._currentUser.asReadonly(); public isAuthenticated = computed(() => this._currentUser()?.isAuthenticated ?? false); /** Valida credenciales requeridas: admin/123 y operador/123 (Requisito Sección 4) */ public login(user: string, pass: string): boolean { let sessionData: UserSession | null = null; if (user === 'admin' && pass === '123') { sessionData = { username: user, role: 'admin', isAuthenticated: true }; } else if (user === 'operador' && pass === '123') { sessionData = { username: user, role: 'user', isAuthenticated: true }; } if (sessionData) { // 1. Actualizar memoria reactiva this._currentUser.set(sessionData); // 2. Persistir en el navegador (Web Storage API) sessionStorage.setItem(this.STORAGE_KEY, JSON.stringify(sessionData)); return true; } return false; } public logout(): void { sessionStorage.removeItem(this.STORAGE_KEY); this._currentUser.set(null); } private readSessionFromStorage(): UserSession | null { const raw = sessionStorage.getItem(this.STORAGE_KEY); if (!raw) return null; try { return JSON.parse(raw) as UserSession; } catch { sessionStorage.removeItem(this.STORAGE_KEY); return null; } } }
2. auth.guard.ts (Functional Guard) CanActivateFn
import { inject } from '@angular/core'; import { CanActivateFn, Router, UrlTree } from '@angular/router'; import { AuthService } from '../services/auth.service'; export const authGuard: CanActivateFn = (route, state): boolean | UrlTree => { const auth = inject(AuthService); const router = inject(Router); if (auth.isAuthenticated()) { return true; } // Redirección atómica reteniendo la URL solicitada return router.createUrlTree(['/login'], { queryParams: { returnUrl: state.url } }); };
3. role.guard.ts (Factoría RBAC) Propuesta 4.2
import { inject } from '@angular/core'; import { CanActivateFn, Router, UrlTree } from '@angular/router'; import { AuthService } from '../services/auth.service'; export const roleGuard = (allowedRole: 'admin' | 'user' | string): CanActivateFn => { return (route, state): boolean | UrlTree => { const auth = inject(AuthService); const router = inject(Router); const session = auth.currentUser(); if (!auth.isAuthenticated() || !session) { return router.createUrlTree(['/login'], { queryParams: { returnUrl: state.url } }); } if (session.role === allowedRole) { return true; } // Si rol 'user' intenta entrar en /admin ➔ redirige a /user-dashboard if (session.role === 'user') { return router.createUrlTree(['/user-dashboard']); } return router.createUrlTree(['/admin']); }; };

@Component({ selector: 'app-login', templateUrl: './login.page.html', styleUrls: ['./login.page.scss'], standalone: true, imports: [CommonModule, FormsModule, IonContent, IonHeader, ...] }) export class LoginPage implements OnInit { private auth = inject(AuthService); private router = inject(Router); private route = inject(ActivatedRoute); public username = ''; public password = ''; public errorMessage = ''; ngOnInit(): void { if (this.auth.isAuthenticated()) { const role = this.auth.currentUser()?.role; this.router.navigate([role === 'admin' ? '/admin' : '/user-dashboard']); } } public handleLogin(): void { const ok = this.auth.login(this.username, this.password); if (ok) { const s = this.auth.currentUser(); const ret = this.route.snapshot.queryParams['returnUrl']; if (ret && !(ret.startsWith('/admin') && s?.role === 'user')) { this.router.navigateByUrl(ret); } else { this.router.navigate([s?.role === 'admin' ? '/admin' : '/user-dashboard']); } } else { this.errorMessage = 'Credenciales no autorizadas. Use admin / 123 u operador / 123'; } } }
